# Starter

A web page built from three files: `index.html`, `style.css` and `main.ts`.

## First time

```sh
npm install
```

## Every time

```sh
npm run dev
```

This opens the page in your browser. Save a file and the page updates.

```sh
npm run check
```

This checks your TypeScript for mistakes. The page can still run when
the check fails, so run it before you call something done.
